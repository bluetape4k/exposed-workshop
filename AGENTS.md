## Exposed Rules

- DSL uses `object Table` plus `transaction { }`.
- DAO uses `Entity` and `EntityClass`.
- Coroutine examples use `newSuspendedTransaction { }` and
  `suspendedTransactionAsync { }`.
- Use `org.jetbrains.exposed.v1.*` imports.

## Tests

- Shared infrastructure lives in `00-shared/exposed-shared-tests`.
- `TestDB`: H2, PostgreSQL, MySQL V8, MariaDB.
- `USE_FAST_DB=true` limits runs to H2.
- Use `AbstractExposedTest`, `enableDialects()`, `WithTables`, and
  `WithTablesSuspending`.
- Parallel tests are serialized with `maxParallelUsages = 1`.

## Dependencies and Compiler

- BOMs: bluetape4k, Exposed, kotlinx coroutines, Spring Boot.
- Versions live in `buildSrc/src/main/kotlin/Libs.kt`.
- Compiler opts include coroutine experimental APIs, `-Xcontext-parameters`,
  and preview JVM support.
