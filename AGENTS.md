# AGENTS.md - exposed-workshop

Kotlin Exposed ORM workshop using Kotlin 2.3, Java 21, Spring Boot 3.x, and a
Gradle multi-module layout.

## Commands

```bash
./gradlew clean build
./gradlew :05-exposed-dml:01-dml:test
./gradlew detekt
repo-status
repo-diff
repo-test-summary -- ./gradlew :MODULE:test
```

Module paths use the leaf directory name generated by `settings.gradle.kts`,
for example:

- `:04-exposed-repository:test`
- `:01-multitenant-spring-web:test`

## Layout

| Directory | Purpose |
|---|---|
| `00-shared/exposed-shared-tests` | Shared test utilities |
| `01-spring-boot` | Spring MVC and WebFlux examples |
| `02-alternatives-to-jpa` | R2DBC, Vert.x, Hibernate Reactive |
| `03-exposed-basic` | Basic DSL and DAO patterns |
| `04-exposed-ddl` | Connection setup and schema DDL |
| `05-exposed-dml` | SELECT, INSERT, UPDATE, DELETE, transactions |
| `06-advanced` | JSON, encryption, custom types, money |
| `07-jpa` | JPA to Exposed migration |
| `08-coroutines` | Coroutines and virtual threads |
| `09-spring` | Spring transactions, cache, repositories |
| `10-multi-tenant` | Schema-based multi-tenancy |
| `11-high-performance` | Cache strategies, routing datasource, benchmarks |

## Exposed Rules

- DSL uses `object Table` plus `transaction { }`.
- DAO uses `Entity` and `EntityClass`.
- Coroutine examples use `newSuspendedTransaction { }` and
  `suspendedTransactionAsync { }`.
- Use `org.jetbrains.exposed.v1.*` imports.

## Tests

- Shared infrastructure lives in `00-shared/exposed-shared-tests`.
- `TestDB`: H2, PostgreSQL, MySQL V8, MariaDB.
- `USE_FAST_DB=true` limits runs to H2.
- Use `AbstractExposedTest`, `enableDialects()`, `WithTables`, and
  `WithTablesSuspending`.
- Parallel tests are serialized with `maxParallelUsages = 1`.

## Dependencies and Compiler

- BOMs: bluetape4k, Exposed, kotlinx coroutines, Spring Boot.
- Versions live in `buildSrc/src/main/kotlin/Libs.kt`.
- Compiler opts include coroutine experimental APIs, `-Xcontext-parameters`,
  and preview JVM support.
